# Pocket SSH Terminal

Hjemmesiden for Pocket SSH Terminal, en SSH terminal til Android. Siden vises med GitHub Pages fra roden af grenen `main`.

Repoet er offentligt og indeholder kun tekster til siden. Appens kode ligger et andet sted.

Engelsk ligger i roden og dansk i `da/`. Hver side linker til samme side på det andet sprog.

| Engelsk | Dansk | Indhold |
|---|---|---|
| `index.html` | `da/index.html` | Forside |
| `getting-started.html` | `da/kom-i-gang.html` | Kom i gang i fem trin |
| `support.html` | `da/support.html` | Support og kontakt |
| `privacy.html` | `da/privatlivspolitik.html` | Privatlivspolitikken, som Google Play linker til |

`style.css` er fælles for begge sprog. `privatlivspolitik.html` og `kom-i-gang.html` i roden sender videre til de danske sider, så gamle links virker.

Intet her må handle om en bestemt server, adresse eller bruger.
