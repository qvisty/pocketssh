# Pocket SSH Terminal

Hjemmesiden for Pocket SSH Terminal, en SSH terminal til Android. Siden vises med GitHub Pages fra roden af grenen `main`.

Repoet er offentligt og indeholder kun tekster til siden. Appens kode ligger et andet sted.

| Fil | Indhold |
|---|---|
| `index.html` | Forside |
| `kom-i-gang.html` | Kom i gang i fem trin |
| `support.html` | Support og kontakt |
| `privatlivspolitik.html` | Privatlivspolitikken, som Google Play linker til |
| `style.css` | Fælles udseende, lyst og mørkt tema |

Intet her må handle om en bestemt server, adresse eller bruger.
