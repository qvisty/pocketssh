Das SSH Terminal, dem du deine Server anvertrauen kannst

Erreiche jeden Linux Server von deinem Android Telefon. Deine Schlüssel bleiben hinter deinem Fingerabdruck, und nichts über dich oder deine Server verlässt jemals das Telefon.

7 Tage kostenlos. Danach ein fairer Einmalpreis oder ein kleines Monatsabo. Kein Konto nötig. Die App ist auf Englisch.

Warum Pocket SSH

Deine Schlüssel verlassen nie dein Telefon

Schlüssel werden auf dem Gerät erzeugt und im sicheren Schlüsselspeicher von Android verschlossen. Jede Verbindung braucht deinen Fingerabdruck oder deine Displaysperre, ohne dich sind die Schlüssel nutzlos.

Kein Konto. Keine Cloud. Kein Tracking.

Es gibt nichts zu registrieren und keinen Server von uns dazwischen. Deine Server, Schlüssel und Befehle bleiben auf deinem Telefon. Die App hat keine Analyse und keine Werbung.

Funktioniert mit jedem SSH Server

Ein VPS, ein Raspberry Pi, ein NAS, ein Heimserver oder der Rechner bei der Arbeit. Spricht er SSH, erreichst du ihn, mit Schlüssel oder Passwort. Schlüssel werden empfohlen, ein Passwort kann hinter deinem Fingerabdruck gespeichert werden.

Stoppt Man in the Middle Angriffe

Die App merkt sich den Host Key jedes Servers. Ändert er sich je, stoppt die Verbindung, bis du ihn geprüft hast. Kein stilles „Ja“ zu einem Fremden.

Einfügen ohne Überraschungen

Bevor eingefügter Text gesendet wird, zeigt die App versteckte Zeichen, Steuerzeichen und Windows Zeilenenden. Skripte laufen genau so, wie sie angezeigt werden, Byte für Byte.

Ein Terminal für deine Daumen

Extratasten für Esc, Tab, Strg und Pfeile. Lieblingsbefehle mit einem Tipp. Die Verbindung überlebt den App Wechsel, und tmux macht dort weiter, wo du aufgehört hast.

Ausgaben wiederfinden

Durchsuche alles, was der Server ausgegeben hat, auch was längst weggescrollt ist. Der Verlauf hält jeden Befehl mit seiner Ausgabe fest, bereit zum Kopieren.

Prüfen vor dem Verbinden

Der Test Knopf zeigt, ob der Server antwortet und welchen Host Key er hat, ohne sich anzumelden.

Noch besser mit Tailscale

Mit Tailscale muss SSH nie offen im Internet stehen. Die App versteht dein Tailnet: Sie nutzt den MagicDNS Namen als Rückfall und sagt dir, wenn Tailscale ausgeschaltet ist, damit du nicht rätseln musst, warum nichts antwortet.

Für wen

  • Entwickler mit einem VPS, die einen Dienst vom Sofa aus neu starten wollen.
  • Selfhoster und Homelab Fans mit Docker, Nextcloud oder Home Assistant.
  • Admins, die einen sicheren Zugang brauchen, wenn der Laptop nicht greifbar ist.
