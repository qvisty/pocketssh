Erste Schritte

Du brauchst nur einen Linux Server, den du per SSH erreichst. Beim ersten Mal dauert es etwa zehn Minuten. Die vollständige Anleitung findest du auch in der App unter Settings, Setup guide. Die App selbst ist auf Englisch.

1. Sicherstellen, dass der Server erreichbar ist

Verwende die IP Adresse oder den Hostnamen des Servers, genau wie vom Computer aus. Soll SSH nicht offen im Internet stehen? Installiere Tailscale auf Server und Telefon, melde dich mit demselben Konto an und verwende stattdessen die Tailscale Adresse des Servers. Dieser Schritt ist optional.

2. Einen Schlüssel in der App erzeugen

Geh zu Keys und erzeuge einen neuen Ed25519 Schlüssel. Die App zeigt den öffentlichen Teil als fertige Zeile für authorized_keys. Der private Teil verlässt nie das Telefon. Lieber mit Passwort anmelden? Das geht auch, wähle dann im Serverprofil unter Login die Option Password.

3. Den Schlüssel auf den Server legen

Füge die Zeile für deinen Benutzer auf dem Server in ~/.ssh/authorized_keys ein.

4. Den Server in der App anlegen

Gib die Adresse des Servers und deinen Benutzernamen ein und wähle den Schlüssel. Tippe auf Test, um zu sehen, ob der Server erreichbar ist.

5. Den Fingerabdruck des Servers prüfen

Beim ersten Mal zeigt die App den Fingerabdruck des Servers. Vergleiche ihn mit dem, was der Server selbst anzeigt, bevor du ihn bestätigst:

ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub

Stimmt er überein, bist du verbunden.
