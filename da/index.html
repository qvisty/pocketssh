Din egen server i lommen

En SSH terminal til Android, lavet til dig, der har din egen Linux server og vil nå den fra telefonen uden at slække på sikkerheden.

Sikkerhed først

  • SSH nøgler laves på telefonen og krypteres i Androids sikre nøglelager. Hver brug kræver fingeraftryk eller skærmlås.
  • Streng kontrol af serverens host key. En ukendt eller ændret nøgle stopper forbindelsen, indtil du har kontrolleret den.
  • Indsat tekst gennemses for skjulte tegn og kontroltegn, før den sendes.
  • Ingen reklamer, ingen sporing, ingen analyse.

En rigtig terminal

  • Farver, vim, htop, nano og tmux.
  • Ekstra taster til Esc, Tab, Ctrl, Alt og piletaster.
  • Forbindelsen holdes åben, når du skifter app.
  • Søg i alt output og se hver kommando med sit output i historikken.

Almindelig SSH eller Tailscale

Forbind til enhver SSH server med IP adresse eller hostname. Bruger du Tailscale, behøver SSH aldrig at være åben mod internettet, og appen hjælper dig, hvis Tailscale ikke er forbundet. Knappen Test viser, om serveren kan nås, uden at logge ind.

Pris

Gratis i 7 dage. Derefter Pro som engangskøb eller månedligt abonnement gennem Google Play. Dine data låses aldrig, kun nye forbindelser.
