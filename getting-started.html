Getting started

All you need is a Linux server you can reach with SSH. It takes about ten minutes the first time. The full guide is also inside the app under Settings, Setup guide.

1. Make sure the server can be reached

Use the server's IP address or hostname, as you would from a computer. Want to keep SSH closed to the internet? Install Tailscale on the server and the phone, sign in with the same account, and use the server's Tailscale address instead. That step is optional.

2. Create a key in the app

Go to Keys and create a new Ed25519 key. The app shows the public part as a ready made line for authorized_keys. The private part never leaves the phone.

3. Put the key on the server

Add the line to ~/.ssh/authorized_keys for your user on the server.

4. Add the server in the app

Enter the server's address and your user name, and pick the key. Tap Test to see that the server can be reached.

5. Check the server's fingerprint

The first time, the app shows the server's fingerprint. Compare it with what the server itself shows before you accept:

ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub

If it matches, you are connected.
