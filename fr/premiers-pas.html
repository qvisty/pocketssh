Premiers pas

Il vous faut seulement un serveur Linux joignable en SSH. Comptez environ dix minutes la première fois. Le guide complet se trouve aussi dans l'application, sous Settings > Setup guide. L'application est en anglais, c'est pourquoi les menus sont cités ici sous leur nom anglais.

1. Vérifier que le serveur est joignable

Utilisez l'adresse IP ou le nom d'hôte du serveur, comme depuis un ordinateur. Vous préférez ne pas exposer SSH sur Internet ? Installez Tailscale sur le serveur et sur le téléphone, ouvrez une session avec le même compte et utilisez plutôt l'adresse Tailscale du serveur. Cette étape est facultative.

2. Créer une clé dans l'application

Allez dans Keys et créez une nouvelle clé Ed25519. L'application affiche la partie publique sous forme de ligne prête à coller dans authorized_keys. La partie privée ne quitte jamais le téléphone. Vous préférez un mot de passe ? C'est possible aussi : dans le profil du serveur, choisissez Password sous Login.

3. Placer la clé sur le serveur

Ajoutez la ligne au fichier ~/.ssh/authorized_keys de votre utilisateur sur le serveur.

4. Ajouter le serveur dans l'application

Saisissez l'adresse du serveur et votre nom d'utilisateur, puis choisissez la clé. Appuyez sur Test pour vérifier que le serveur est joignable.

5. Vérifier l'empreinte du serveur

La première fois, l'application affiche l'empreinte du serveur. Avant de l'accepter, comparez cette empreinte avec celle qu'affiche le serveur :

ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub

Si elles correspondent, vous êtes connecté.
