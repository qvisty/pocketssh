Your own server in your pocket

An SSH terminal for Android, made for people who run their own Linux server and want to reach it from their phone without cutting corners on security.

Security first

  • SSH keys are created on the phone and encrypted in Android's secure key store. Every use needs your fingerprint or screen lock.
  • Strict host key checking. An unknown or changed key stops the connection until you have verified it.
  • Pasted text is checked for hidden and control characters before it is sent.
  • No ads, no tracking, no analytics.

A real terminal

  • Colors, vim, htop, nano and tmux.
  • Extra keys for Esc, Tab, Ctrl, Alt and arrows.
  • The connection stays open when you switch apps.
  • Search all output and see every command with its output in the history.

Plain SSH or Tailscale

Connect to any SSH server by IP address or hostname. With Tailscale, SSH never has to be open to the internet, and the app helps you when Tailscale is not connected. The Test button shows whether the server can be reached, without logging in.
